# Invoice print PNGs

Drop artwork here for Sales Tax Invoice print preview (`src/lib/printInvoice.ts`).

| File | Use |
| --- | --- |
| `stamp.png` | Company stamp (bottom-right of sign row) |
| `signature.png` | Approved-by signature |
| `corner-top-left.png` | Top-left page corner shape |
| `shape-bottom.png` | Bottom page decorative shape |

Paths resolve as `/invoice-print/<filename>`.
